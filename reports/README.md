# TunSociety PFE LaTeX Report

This folder contains the LaTeX source of the TunSociety final year project report.

Main file: `main.tex`

The report is organized into front matter, chapters, appendices, tables, figures, and bibliography files. Keep edits scoped to this folder when working on the report.

Recommended compile command:
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
